# Gobbler logo

The turkey from the widget's done screen, as a square logo. Drawn in SVG, so it scales to any size.

- `gobbler-logo.svg` and `.png`: on a warm cream square. Use this for app icons and plugin store listings.
- `gobbler-logo-transparent.svg` and `.png`: no background, for putting on other colours.

The PNGs are 1024 by 1024. The drawing matches `workers/mcp/widget/src/main.ts`, with fixed colours instead of the widget's theme colours. If the turkey changes there, redraw these too.
